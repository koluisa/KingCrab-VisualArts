# 🦀 King Crab Visual Arts

Bem-vindo ao **King Crab Visual Arts**, um site desenvolvido para apresentar e divulgar trabalhos de arte visual, reunindo criatividade, identidade e expressão artística em um só lugar.

## 🎨 Sobre o projeto

O **King Crab Visual Arts** é um projeto de site voltado ao universo das artes visuais. A proposta é criar um espaço digital onde diferentes trabalhos artísticos possam ser apresentados de maneira organizada, moderna e visualmente atrativa.

O site foi desenvolvido como um projeto acadêmico de desenvolvimento web, utilizando tecnologias fundamentais para a criação de páginas na internet.

## 🚀 Tecnologias utilizadas

- **HTML5** — Estruturação das páginas
- **CSS3** — Estilização, layout e identidade visual
- **JavaScript** — Interatividade e funcionalidades
- **Imagens** — Composição visual e apresentação das obras
- **Vídeos** — Conteúdo audiovisual relacionado aos trabalhos

## 🖼️ Proposta visual

A identidade do **King Crab Visual Arts** busca transmitir:

- 🎨 Criatividade
- 🦀 Originalidade
- ✨ Expressão artística
- 🖌️ Cultura visual
- 💡 Inovação

O design foi pensado para valorizar o conteúdo artístico e proporcionar uma navegação simples e agradável ao visitante.

## 🌐 Funcionalidades

O site conta com páginas e elementos destinados a:

- Apresentação da King Crab Visual Arts;
- Exibição de trabalhos artísticos;
- Navegação entre diferentes páginas;
- Utilização de imagens e vídeos;
- Organização do conteúdo por categorias;
- Elementos interativos utilizando JavaScript.

## 💻 Como executar o projeto

Para visualizar o site localmente:

1. Baixe ou clone este repositório.
2. Mantenha a estrutura de pastas do projeto.
3. Abra a pasta do projeto no **Visual Studio Code** ou outro editor.
4. Abra o arquivo:

```text
html/index.html
```

5. Execute o arquivo em um navegador.

> **Importante:** mantenha os caminhos relativos entre as pastas `html`, `css`, `javascript`, `imagens` e `videos` para que todos os recursos funcionem corretamente.
